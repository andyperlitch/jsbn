jsbn

Try the API in the browser, then run a timed suite against the three libraries that occupy the same niche today: bn.js, big-integer, and bignumber.js.

Bits & number theory

Result

—

Each library runs the same integer workload, one library at a time, so they do not contend for the same event-loop slice. Times are wall clock in this browser. After each timed op, the result is checked once against native BigInt (not included in the time). A mismatch marks the cell fail. Divide and mod use a double-width dividend; modPow uses a 256-bit exponent against a full-width odd modulus. big-integer wraps native BigInt when the engine provides it.
